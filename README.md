# 🐾 PawStay AI – Intelligent Pet Home-Stay & Caregiver Platform

**PawStay AI** is an AI-powered pet-care platform designed to connect pet owners with trusted caregivers, pet service providers, and sellers through a unified mobile application. It uses AI-driven recommendations, location-based services, and a microservices architecture to provide personalised and convenient pet-care services.

## 🚀 Key Features

- **AI-Powered Recommendations:** Intelligent caregiver recommendations based on pet requirements, breed, age, behaviour, and caregiver experience.
- **Multi-LLM Integration:** Integrated 4 NVIDIA-powered LLM models to support AI-driven pet-care assistance.
- **Pet Care Assistant:** AI assistant providing general guidance on pet nutrition, grooming, and behaviour.
- **Location-Based Services:** Integrated self-hosted maps for discovering nearby caregivers and pet-care services.
- **Real-Time Messaging:** Socket.IO-based communication between pet owners and caregivers.
- **Secure Authentication:** Email OTP verification and HTTP-based SMS integration to reduce mobile SMS costs.
- **Online Payments:** Razorpay payment gateway integration for secure transactions.
- **Pet Walking Services:** Connects pet owners with service providers for pet walking and temporary care.
- **Microservices Architecture:** Independent backend services for authentication, users, caregivers, sellers, messaging, and payments.
- **Role-Based Dashboards:** Dedicated dashboards for pet owners, caregivers, and sellers.

PawStay AI follows a microservices-based architecture in which the Flutter mobile application communicates with independent backend services through APIs.
